# แผนที่ใช้ MapLibre GL JS + PMTiles ที่ host เอง ไม่ใช้ Google Maps หรือ Mapbox

แผนที่จุดน้ำท่วมเป็นหน้าสาธารณะ และคนจะเข้าพร้อมกันมากที่สุดตอนน้ำท่วมจริง ถ้าใช้บริการที่คิดเงินตามจำนวนครั้งที่โหลดแผนที่ ค่าใช้จ่ายจะพุ่งหรือแผนที่จะหยุดทำงานในช่วงที่คนต้องใช้มากที่สุด จึงเลือกใช้ MapLibre GL JS (โอเพนซอร์ส ไม่ต้องมี API key) วาดแผนที่จากไฟล์ PMTiles ของ Protomaps ที่ตัดเฉพาะพื้นที่กรุงเทพฯ และปริมณฑลจากข้อมูล OpenStreetMap แล้ววางเป็นไฟล์ static ของเราเอง ต้นทุนจึงเหลือแค่ค่า bandwidth ไม่ขึ้นกับจำนวนครั้งที่โหลด

## Considered Options

- **Google Maps (Dynamic Maps):** ฟรี 10,000 loads ต่อเดือน เกินแล้วประมาณ $7 ต่อ 1,000 loads ต้องผูกบัตร และตั้งแต่มีนาคม 2025 ไม่มีเครดิต $200 แล้ว คนเข้าช่วงน้ำท่วมวันเดียวก็อาจใช้โควตาหมด ไม่เลือก
- **Mapbox GL JS:** ฟรี 50,000 loads ต่อเดือน ไม่ต้องใช้บัตร เกินแล้วประมาณ $5 ต่อ 1,000 loads มีปัญหาเรื่องช่วงที่คนเข้าพร้อมกันแบบเดียวกัน และ token ที่ฝังในหน้าเว็บถูกเอาไปใช้ต่อได้ ไม่เลือก แต่ API ของ MapLibre แทบเหมือน Mapbox GL ถ้าวันหนึ่งอยากย้ายก็ทำได้ไม่ยาก
- **Tile server ของ OpenStreetMap (`tile.openstreetmap.org`):** ฟรี แต่ usage policy ไม่อนุญาตให้แอปที่มีคนใช้มากดึงจาก server นี้โดยตรง ไม่เลือก
- **Longdo Map:** ป้ายชื่อภาษาไทยดี ยังไม่ได้ตรวจเงื่อนไข free tier ถ้าป้ายชื่อจาก OSM ไม่พอ ค่อยกลับมาดู

## Consequences

- **ไม่ได้แก้ข้อห้ามเรื่องพิกัด:** API ยังไม่เก็บพิกัดตาม spec §5 และ RPT-REQ-013 หมุดจึงวางได้แค่ตำแหน่งโดยประมาณจากเขต ถ้าจะปักตรงจุดจริงต้องแก้ spec และตัดสินเรื่อง PDPA (Q9) ก่อน ถ้าเพิ่มพิกัด ควรปัดเศษให้หยาบประมาณ 100 m ก่อนเก็บ
- **ต้อง host ไฟล์ของแผนที่ทุกอย่างเอง:** ไฟล์ `.pmtiles`, style, ฟอนต์ (glyphs), sprite และตัว MapLibre GL JS, pmtiles, basemaps (JS/CSS) ไม่โหลดจาก CDN หรือโดเมนอื่นเลย เหตุผลเดียวกับที่ไม่ใช้ Google Maps คือไม่ให้ IP ของผู้ชมไปถึงบุคคลที่สาม และไม่ให้แผนที่ล่มตาม CDN ในช่วงที่คนเข้าเยอะ glyphs เอาเฉพาะช่วงไทย ละติน และเครื่องหมายวรรคตอน ชื่อภาษาอื่นบนแผนที่จึงไม่แสดง ที่เก็บไฟล์ tiles ต้องรองรับ HTTP Range request และต้องตัดไฟล์ใหม่เป็นระยะเพื่อให้ถนนหรือชื่อสถานที่ไม่เก่าเกินไป
- **ต้องแสดง attribution:** "© OpenStreetMap contributors" บนแผนที่ตามสัญญาอนุญาต ODbL
- **ไม่ต้องมี API key และไม่มีบิลที่พุ่งตามคนใช้:** แลกกับการที่ต้องดูแลไฟล์แผนที่เอง
- **ตัวเลขราคาเป็นของเดือนกันยายน 2026:** ก่อนตัดสินใจจริงควรตรวจอีกครั้งที่ [Google Maps Platform pricing](https://developers.google.com/maps/billing-and-pricing/pricing) และ [Mapbox pricing](https://www.mapbox.com/pricing)
