# Intent: คูปองส่วนลดตอน checkout

> Owner: ทีมร้านค้า · Date: 2026-09-30 · Status: agreed

## Problem

ลูกค้าที่ได้โค้ดส่วนลดจากแคมเปญ (อีเมล, โพสต์ในเพจ) ไม่มีที่กรอกตอนจ่ายเงิน ทีมต้องทักไปคืนเงินทีหลังทีละออเดอร์
ช่วงแคมเปญมีออเดอร์แบบนี้วันละหลายสิบรายการ และคืนเงินผิดบ่อย

## Proposed outcome

- ลูกค้ากรอกโค้ดคูปองตอนขอราคา แล้วเห็นส่วนลดและยอดสุทธิทันที
- ทีมไม่ต้องคืนเงินเองสำหรับออเดอร์ที่ใช้คูปองผ่านหน้าร้าน
- วัดผล: ออเดอร์ที่ต้องคืนเงินเพราะคูปองลดลงเหลือศูนย์ในแคมเปญถัดไป

## Constraints

- **ความปลอดภัย:** ต้องกันคนสุ่มเดาโค้ด ข้อความตอบกลับต้องไม่บอกว่าโค้ดนั้นมีอยู่จริงหรือไม่
- **เงิน:** คิดเป็นสตางค์ (จำนวนเต็ม) ส่วนลดต้องไม่ทำให้ยอดติดลบ
- **ขอบเขต:** หนึ่งออเดอร์ใช้ได้หนึ่งคูปอง ใช้ร่วมกับโปรอื่นไม่ได้
- **ห้ามแตะ:** โครงสร้างราคาสินค้าและ `priceCart` เดิม
